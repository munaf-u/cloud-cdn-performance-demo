CDN evidence

After deployment, open Developer Tools → Network, reload this page, and select /assets/test.svg.

  • Server: cloudflare and CF-Ray indicate the request passed through Cloudflare.
  • CF-Cache-Status, if present, describes the cache decision. HIT means served from cache; MISS means it was not already cached.
  • Record the response headers and timings. Do not assume every request must be a HIT.

Experiment procedure

  1. Run the same website locally and record a baseline measurement.
  2. Deploy the unchanged files to Cloudflare Pages.
  3. Open the deployed website from the same device and network.
  4. Measure several requests and inspect the response headers.
  5. Compare the results, noting that local-versus-cloud timing is an illustrative comparison, not a perfectly controlled benchmark.
